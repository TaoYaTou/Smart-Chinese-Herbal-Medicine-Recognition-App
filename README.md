# Smart-Chinese-Herbal-Medicine-Recognition-App
基于轻量化MobileNetV2网络的中药材识别微信小程序，实现移动端中药材智能识别。使用163种中药材数据集训练，采用迁移学习技术微调MobileNetV2，模型在测试集上达到98.34%的识别准确率，模型体积约9.7MB。后端基于Flask框架开发，部署于微信云托管环境；前端采用微信小程序原生开发。功能包括拍照识别、相册选图、识别历史记录、药材详情展示、使用须知管理、联系我们等。适用于基层用药鉴别、中药材流通环节智能化管理、中医药文化科普等场景。A WeChat mini program for Chinese herbal medicine recognition based on the lightweight MobileNetV2 network, enabling intelligent identification of Chinese herbal medicine on mobile devices. The model was trained on a dataset of 163 types of Chinese herbs, with MobileNetV2 fine-tuned using transfer learning. The model achieves an identification accuracy of 98.34% on the test set and has a size of approximately 9.7MB. The backend is developed using the Flask framework and deployed in the WeChat Cloud hosting environment, while the frontend is developed using native WeChat mini program technology. Features include photo recognition, album selection, recognition history, herbal medicine details display, usage instructions management, and contact us. It is suitable for scenarios such as basic drug identification, intelligent management in the circulation of Chinese herbal medicines, and popularization of traditional Chinese medicine culture.
